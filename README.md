Hi, I'm Rio,

I build [Dorsal](https://github.com/dorsalhub/dorsal), a Python library and CLI toolkit for annotating files. It powers [DorsalHub](https://dorsalhub.com), an annotation platform where files are indexed by their hashes and annotated by hand or with models.

I also maintain [OATS](https://github.com/oatschema/oats) (Open Annotation Task Schemas): strict, versioned JSON Schemas for model outputs, with validators for Python, JavaScript and Rust.

I care about data formats, deterministic output, and validation tooling. I mostly write Python and Rust.

Previously: data and engineering at Bloomberg (2018–2023); school teacher (2012–2016). Based in London.
